Clock

The time zone is the standard (winter) offset; summer time adds an hour. Europe: last Sunday of March to last Sunday of October. North America: second Sunday of March to first Sunday of November.

Web Access

A password is set.

With a password set, the browser asks for it (any username), and updates over Wi-Fi can be sent. It's sent unencrypted, so it keeps out other people on your network rather than a determined attacker. Setup mode removes a forgotten one.

Diagnostics

Name

Also its network name (name.local) and MQTT client id. Home Assistant names the light after it. Letters, digits, - and _; used from the next start.

Updates

deploy.ps1 -WiFi <name> sends a new version over Wi-Fi (with a web password set): the device tries it, and goes back to this one if it doesn't start properly.

Restart and Reset

Reset puts every setting on these pages back to its default (the web password too), but keeps the Wi-Fi network and the LED count and type. A factory reset also forgets the name and Wi-Fi, and starts setup mode.

Wi-Fi Network

Connected to …. A new network is used after a restart, on trial: if it can't connect within 5 minutes, the device goes back to this one.

Setup mode is the other way, with no network to reach this page: the device's PlasmaStick-SETUP hotspot and a page at http://192.168.4.1. Holding the button while powering on starts it (or BOOTSEL for 5 s while it runs), as does the fallback below.

Connecting

MQTT lets home automation software such as Home Assistant or Node-RED control the lights.

Broker

A password is set.

Topics

{name} becomes the device name. Topics no longer used are cleared from the broker after the restart.

Group

Devices with the same group name follow each other: turn one on, or change its mode or colour, and the rest do the same (the Unicorn HAT too). A mode another device doesn't have is ignored by it. Letters, digits, - and _.

Home Assistant

Home Assistant adds the light automatically (MQTT discovery), with an Alert button and an Alerts switch. Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.

Clock

The time zone, summer time and time server are on the Device tab.

Location

For sunrise and sunset events. East and north are positive.

Events

Up to 8. Events act like any other change, so a group follows them. After a restart the lights do what the latest event said.

Alerts

With alerts on, an alert interrupts whatever the lights are doing, even when they're off: they flash, then carry on as they were. Alerts come from the topic watched below, Home Assistant's Alert button, MQTT (<base>/alert) or the API (POST /api/alert).

The Alert

Each flash is on, then off, for these times (off 0: steady).

Watch

Another device's topic, such as a Pico PIR's /home/device/pir/state: an alert starts when it says something has happened (motion true, ON, true, or any other message), once until it clears. Needs MQTT.
