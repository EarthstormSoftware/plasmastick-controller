Both keep the LED count and type. Reset settings keeps the Wi-Fi network too; factory reset forgets it, and the device starts its PlasmaStick-SETUP hotspot: join it, then open http://192.168.4.1 to set it up again.

Wi-Fi

To change the Wi-Fi network or its password, hold the button while powering on: the device starts its PlasmaStick-SETUP hotspot. Join it, then open http://192.168.4.1.

Topics

{name} becomes the device name. Topics no longer used are cleared from the broker after the restart.

Group

Devices with the same group name follow each other: turn one on, or change its mode or colour, and the rest do the same. Letters, digits, - and _.

Home Assistant

Home Assistant adds the light automatically (MQTT discovery). Turning this off removes it again. Only change the prefix if Home Assistant's has been changed.

Clock

The time zone is the standard (winter) offset; summer time adds an hour. Europe: last Sunday of March to last Sunday of October. North America: second Sunday of March to first Sunday of November.

Location

For sunrise and sunset events. East and north are positive.

Events

Up to 8. Events act like any other change, so a group follows them. After a restart the lights do what the latest event said.
